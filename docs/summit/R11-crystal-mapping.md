# 控制平面光学映射表（QPS / 健康度 / 故障态 → uniform）

> 面向答辩的解释材料："每一束光都有含义"——视觉上的每一次呼吸、每一次提速、
> 每一次变色，都能对应到一个真实的遥测信号。
> 实现文件：`src/components/canvas/CrystalOptics.tsx`（7 层结构）与
> `src/components/canvas/ArcStartGlow3D.tsx`（弧线起点光斑）。

---

## 1. 输入信号（全部来自既有双轨，不新增采样）

| 信号 | 来源 | 频率 | 说明 |
|---|---|---|---|
| `clusterHealthScore` | `useClusterStore.snapshotSummary` | 1 Hz | 0–100，驱动色温三态 |
| `totalQps` | 瞬态轨 `telemetryTransientRef.snapshot.totalQps` | 1 Hz | 入口 QPS，驱动呼吸与流速 |
| `activeChaos`（隐含） | 健康分联动 | 1 Hz | 故障时健康分下降 → 色温转绯红 |
| `healedPodIds`（隐含） | 健康分回升 | 1 Hz | 恢复后 1.2s 缓动回冰川青 |

> 所有读取都在 `useFrame` 内通过模块级单例完成（`getState()` / 瞬态 ref 直接读属性），
> 不建立 React 订阅，因此每帧零重渲染、零分配。

## 2. QPS → 视觉映射

### 2.1 呼吸（`uBreath`）

```
qpsNorm = min(1, log10(totalQps + 1) / 4)      // [100, 20000] → ≈ [0.5, 1.07]
breath  = 1 + 0.06 * qpsNorm * sin(t * 2.2)    // 幅度 ≤ 6%
```

写入：
- 内核（第 1 层）`uBreath` —— 奇点亮度与流动幅度；
- 雾球（第 2 层）`uBreath` —— 体积光强度；
- 大气光晕（第 6 层）`uBreath` —— 轮廓泛光强度。

**答辩口径**：业务流量越高，中心能量呼吸越明显；上限 6% 是为了避免"心跳过强"
变成视觉噪声——呼吸是状态的证据，不应该是干扰。

### 2.2 流光速度（`uFlowSpeed`）

```
flowSpeed = 1 + 0.6 * qpsNorm
```

- 棱线（第 4 层）`uFlowSpeed` —— 沿边 `sin(vT*18 − time*2.4*flowSpeed)` 的流光推进速度；
- 内部星云旋转：`rotation.y = t * 0.22 * (1 + 0.5 * qpsNorm)`。

**答辩口径**：流量越高，能量沿棱线/星云流动得越快——"数据在结构里跑"而不是静态装饰。

### 2.3 星芒脉冲（第 1.5 层，屏幕空间星芒）

```
uPulse = 0.72 + 0.28 * max(0, sin(t * 2.2 + π/3))
```

- 与呼吸同频段（2.2 rad/s），但**相位错开**，避免所有光效同时亮暗；
- 星芒只在晶核屏幕投影处（1 draw call、四瓣、宽度 ≤ 晶核屏幕直径 1.6×），
  **绝不做整屏横竖条**：shader 内以 `smoothstep(0.42, 0.5, radius)` 硬裁切。

## 3. 健康度 / 故障态 → 色温映射

| 健康分 | 目标色 | 动画 |
|---|---|---|
| ≥ 90（健康） | 冰川青 `#38bdf8`，内核近白 `#00f2fe` | 常规阻尼 k=2.2 |
| 70–89（高负载） | 琥珀 `#fbbf24` | 常规阻尼 k=2.2 |
| < 70（故障） | 绯红 `#f43f5e` | 常规阻尼 k=2.2 |
| 故障 → 健康（恢复） | 回到冰川青 | **1.2s 慢缓动** k≈0.83 |

实现：预分配 `toneCurrent` / `toneTarget`，`toneCurrent.lerp(toneTarget, 1 − e^(−k·dt))`，
再 `copy()` 到各层 uniform（内核 `uColorCool/uColorDeep`、雾球、晶体 `uTint`、棱线、星云、大气）。

**答辩口径**：颜色不是氛围灯，是告警语义——绿/琥珀/绯红分别对应健康/高负载/故障；
恢复时用 1.2s 缓动，是为了让"系统恢复"看起来是过程而不是开关。

## 4. 故障态下的额外视觉证据

| 视觉 | 触发 | uniform / 参数 |
|---|---|---|
| 棱线中段漏光 | 晶核脉冲（始终） | `uLeak = 0.25 + 0.75·max(0, sin(2.2t))`，中段 `exp(-((t−0.5)/0.22)²)` 提亮并向两端扩散 |
| 弧线起点汇聚光斑 | 每 1.5s/车道相位错开 | `ArcStartGlow3D`：0.15s 高亮窗口，亮度平方衰减、尺寸收缩 |
| 高 QPS 的内部涡旋加速 | `qpsNorm` | 星云 `rotation.y` 乘 `(1+0.5·qpsNorm)` |

## 5. 低档位（T1/T0）降级映射

| 项 | T2/T3 | T1/T0 |
|---|---|---|
| 内部星云粒子 | 360 | **120**（`buildNebulaGeometry(120)`） |
| 噪声音频倍频 | 3（fbm3 三倍频） | **1**（`#define KV_LOW_NOISE` 关闭倍频 2/3） |
| 晶体主体 | T3 可用 `MeshPhysicalMaterial` 真折射 | **Fresnel 假折射 shader**（成本恒定） |
| 星芒 / 色温 / 陀螺仪骨架 | 保留 | 保留（各 1 draw call，属最低限度光学语义） |
| 顶部光柱 | 无 | **无**（R25 已删除 godray/pillar/flare，R26 清除最后 4 处残留常量） |

## 6. 一图流（答辩口述版）

```
QPS ──► 呼吸幅度 (≤6%) ──► 内核 / 雾球 / 大气
    └─► 流速 (1+0.6n) ──► 棱线流光 / 星云涡旋

健康分 ──► 色温目标 ──► 青 / 琥珀 / 绯红 ──► 所有层 uniform
    └─► 恢复 1.2s 缓动

晶核脉冲 ──► 棱线漏光 uLeak + 星芒脉冲 uPulse（相位错开）

低档位 ──► 星云 120 颗 + 单倍频噪声 + Fresnel 假折射 + 无顶部光柱
```
