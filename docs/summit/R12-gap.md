## R13 待办（按影响排序）

1. **A4 刀片生命感**（机架质感 3→4 的关键）：3 状态灯 + CPU 负载活动条，InstancedMesh 1–2 draw calls。
2. **真机景深验收**（景深 3→4）：T3 焦内外分布实测 + 参数标定。
3. **拖尾负载映射**（拖尾 3→4）：`COMET` 频率/密度由 CPU/网络吞吐驱动，丢包随机熄灭。
4. **地面反射一致性**（地面 3→4）：真机反射 pass 与低档位反射带的观感对齐。
5. **aoMap 盒状模糊**（机架质感细节）：补齐 uv1 与 256² 程序化 AO。
