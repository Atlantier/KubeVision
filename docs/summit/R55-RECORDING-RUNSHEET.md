## 1. 录前 10 分钟

1. `pnpm build && pnpm start`；浏览器 F11 全屏、Ctrl+0 还原缩放；
2. 系统缩放 100%、指针轨迹关闭、勿扰开、TTS/通知关；
3. OBS：1080p30 / CQP20 / AAC192，只留麦克风；开 `mp4 + mkv` 双录制；
4. 先空录 10 秒确认音画与分辨率；再按 §2 走一遍不录（走位）；
5. 计时器不可见；分镜卡放手边；主讲与操作者同一人时先练两次点击。

## 4. 录制与取优

1. 共录 **3 遍**；每遍开头说「第 N 遍开始」、结尾「第 N 遍结束」做同步标记；

4. 导出：H.264 MP4 / 1080p30 / CQP20 / AAC192；文件名见 §6。
