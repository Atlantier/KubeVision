## 3. 录制与取优

1. 共录 **3 遍**；每遍开头说「第 N 遍开始」、结尾「第 N 遍结束」做同步标记；
2. 按「完整度 > 无嘴瓢 > 时长」选一遍；失败段不解释，整段重录；
3. 剪辑只做：对齐开场、删等待、响度标准化（-16 LUFS）；不加滤镜/音乐；
4. 导出：H.264 MP4 / 1080p30 / CQP20 / AAC192；文件名见 §4。
