# R54 · 录屏工程化手册（RECORDING KIT）

> 目标：一次录制 = 一条 3:00 主讲版 + 一条 60s 无旁白版，全程 **1920×1080 / 30fps / 100% 缩放**，
> 无鼠标抖动、无系统通知、无浏览器 UI；录 3 遍取最好；本地 mp4 双备份，**不依赖 B 站**。
> 配套分镜与真实按钮名见 `docs/summit/DEMO_DIRECTOR_PLAYBOOK.md`（R53），本文件只解决"怎么录出来"。

## 1. 录制环境（一次配置，录前三遍复用）

| 项 | 值 | 检查方式 |
|---|---|---|
| 分辨率 | 1920×1080 | 显示设置 → 分辨率 |
| 系统缩放 | **100%**（不是 125%/150%） | 显示设置 → 缩放；录前截图看 UI 字重是否发虚 |
| 浏览器缩放 | **100%**（Ctrl+0） | 地址栏右侧不显示缩放百分比 |
| 浏览器 | 与排练同版本 Edge/Chrome；**隐藏书签栏**（Ctrl+Shift+B）、F11 全屏 | 录前截图 |
| 帧率 | 30fps（OBS 输出与视频都设 30） | OBS 设置 → 视频 |
| 编码 | H.264 / MP4；CQP 20–22；音频 AAC 192kbps 48kHz | OBS 输出 → 录像 |
| 音频 | 主讲用独立 USB 麦（不要用笔记本阵列麦）；OBS 输入 -12dB 峰值 | 录 10s 回放看波形 |
| 通知 | 系统勿扰 + 关闭微信/QQ/邮件 + 浏览器通知权限关 | 录前 1 分钟 |
| 光标 | 系统指针轨迹关闭、指针阴影关闭；OBS **捕获光标=开** | OBS 来源属性 |
| 计时器 | 不可见（手机倒扣，或第二屏） | 开录前确认 |

**OBS 快速参数（1080p30 基准）**
- 基础/输出分辨率：1920×1080；缩小滤镜 Lanczos；
- 常用 FPS：30；输出模式：高级 → 录像；
- 编码器：x264（CPU 够）或 NVENC；码率控制 CQP 20；预设 veryfast；
- 音频：48kHz、立体声；桌面音频**关闭**（避免 TTS/提示音入镜），只留麦克风；
- 来源：窗口采集（浏览器窗口）或显示器采集（更稳，但需藏任务栏）；
- 录制格式：`mp4`（直接可交付）；同时开一份 `mkv` 兜底（防崩溃丢文件，事后重封装 mp4）。

## 2. 鼠标抖动控制 SOP（录制前练 3 次）

1. **能用键盘就不用鼠标**：`Ctrl+K` 命令面板、`Enter` 选中、`Esc` 逐层退出；
2. 每次点击前**先把指针移到目标中心并停 0.3s**，再单击；点完**立刻把指针停到安全区**（画面右下空白/画布边缘），不要悬停在按钮上；
3. 点击动作只做一次，**不做"画圈找按钮"**；找按钮失败就 Esc 重来，不录这段；
4. 关闭 Windows「显示指针轨迹」；鼠标 DPI 固定（不要中途换鼠标）；
5. 若仍抖：OBS 不捕获光标 + 剪辑时加"点击高亮"贴片（后期 5 分钟即可），但**旁白必须与画面同步**；
6. 开场前把指针停在画面外（屏幕边缘），第一个动作再入场。

## 4. 录制流程（3 遍取最好）

1. 录前跑：`pnpm build && pnpm start`；`node scripts/check-dead-exports.mjs` 不阻塞录制可跳过；
2. 开 OBS → 点录制 → **拍手/说"第 N 遍开始"**（音画同步标记，剪辑好对齐）；
3. 按 R53 分镜走；每步点击后停 1.5–2s；失败不要在录制中解释，**整段重录**；
4. 每遍结束说"第 N 遍结束"，停止录制；回放关键三段（注入/自愈/RAG）确认无丢帧；
5. 三遍录完，选**一遍完整版**（优先：无卡顿 > 无嘴瓢 > 时长）；时长目标 2:50–3:05；
6. 用剪映/PR 只做三件事：对齐开场、删开头等待、响度标准化（-16 LUFS）；**不加滤镜/不加音乐**；
7. 导出 MP4（H.264、1080p30、CQP 20、AAC 192k），命名见 §6。

**失败判定（出现即重录该段）**：鼠标画圈找按钮、弹窗遮挡画面、讲错按钮名、系统通知、TTS 出声、分辨率不是 1920×1080。

## 6. 命名与备份（本地 mp4，不依赖 B 站）

```
recording/
  KubeVision_3min_take1.mp4
  KubeVision_3min_take2.mp4
  KubeVision_3min_take3.mp4
  KubeVision_3min_FINAL_1080p30.mp4     ← 交付/展台
  KubeVision_60s_silent_1080p30.mp4     ← 循环/预览
  SHA256SUMS.txt
```

- 生成校验：`Get-FileHash recording/*.mp4 -Algorithm SHA256 > recording/SHA256SUMS.txt`；
- 备份位置：**本机 + U 盘 + 第二台电脑**各一份；上传 B 站仅作为"额外可选"，不作为唯一副本；
- 录完立刻拷贝到 U 盘（不要等剪辑完）；
- 视频不入 git（`.gitignore` 加 `recording/`），只把本手册与校验和提交仓库。

**交付前 QC（逐项打勾）**
- [ ] 分辨率 1920×1080、帧率 30、缩放 100%（用播放器属性看）；
- [ ] 鼠标无画圈/无悬停抖动；无系统通知；无浏览器书签栏；
- [ ] 音频无爆音（峰值 ≤ -3dB）、无 TTS、无键盘声；
- [ ] 时长 2:50–3:05；60s 版恰 58–62s；
- [ ] 关键三处字幕/口播一致：故障演练、立即执行自愈方案、RAG 未命中拒答；
- [ ] SHA256 已记录；U 盘副本可播放（换机验证一次）。
