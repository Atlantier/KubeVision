> **所有市场/财务数字均为假设或估算**（明确标注），不构成营收承诺；无真实客户数据。
> 成本口径来自本仓库最新评测：RAG 路径平均 prompt 5,559 / completion 1,243 tokens、平均 TTFT 756ms（`docs/ai-quality.json`，20 问平均）。

## 3. 商业模式（假设）

1. **私有化授权**：按集群/节点数一次性授权 + 年维护（目标客单价 ¥8–30 万，假设）；
2. **SaaS 订阅**：按集群数 ¥300–800/集群/月（假设），适合无内网要求的客户；
3. **交付/培训**：演示套件、Runbook 共建、答辩/培训服务（假设 ¥2–5 万/次）。

## 4. 单位经济粗算（全部为假设，不是实测账单）

| 项 | 假设值 | 说明 |
|---|---|---|
| 单次 RAG 诊断 tokens | 5,559 in / 1,243 out | `docs/ai-quality.json` 实测均值（TTFT 均值 756ms） |
| LLM 单价（假设） | ¥1 / 百万 input tokens、¥2 / 百万 output tokens | 以国产 flash 级模型为例，实际以供应商为准 |
| 单次模型成本（估算） | **≈ ¥0.008**（约 0.8 分） | 5.559k×1/1M + 1.243k×2/1M |
| 每集群日均诊断（假设） | 20 次 | 值班场景 |
| 每集群月模型成本（估算） | **≈ ¥4.8** | 20×30×0.008 |
| 私有化部署成本（估算） | 服务器/带宽 ¥2–6 万/年 | 信创环境 |
| 毛利率（假设） | 60–75% | 未计研发与交付人力 |

## 5. 90 天 PoC 计划（3 个验证指标）

| 阶段 | 时间 | 动作 | 交付 |
|---|---|---|---|
| P0 环境 | D1–D14 | 只读 K8s 权限 + KubeVision 私有化部署 | 可跑通的演示环境 |
| P1 价值验证 | D15–D45 | 选 2 个高频故障（OOM/CrashLoop），值班人对照使用 | 对照记录 |
| P2 嵌入流程 | D46–D75 | 接入告警 → 3D 定位 → RAG 出处 → 自愈回执/复盘 | 流程 SOP |
| P3 评估 | D76–D90 | 三项指标复盘，决定采购/终止 | PoC 报告 |

**三个验证指标（PoC 目标，非当前实测）**
1. **MTTR 下降**：同类故障平均恢复时间较基线下降 **≥30%**（需客户基线）；
2. **定位耗时**：从告警到"定位到具体 Pod/节点"的中位时间 **≤3 分钟**；
3. **高危操作审计覆盖率**：经 KubeVision 发起的高危动作 **100% 有确认 + 回执 + 复盘**。

> 指标达成需客户真实数据与 90 天周期；本仓库无法自证，只作为 PoC 验收口径。
